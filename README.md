## 特性

- ✅ **海量表情** 偶尔做做热门表情包，也欢迎投稿高清有趣的素材
- ⚡ **实时生成** 支持通过指令快速生成表情
- 🔄 **搭配使用** 需要搭配 [meme-generator](https://github.com/MemeCrafters/meme-generator) 一起使用

## 投稿与反馈

### 投稿素材

> 🚧 欢迎投稿高清素材，看到有趣的素材会制作成表情更新到本仓库！
>
> 通过 Issues 中的「投稿素材」模板提交；若能直接提 PR 则更好 🎉

投稿前建议先阅读 [新表情编写指北](https://github.com/MemeCrafters/meme-generator/wiki/%E6%96%B0%E8%A1%A8%E6%83%85%E7%BC%96%E5%86%99%E6%8C%87%E5%8C%97)，
并确认表情目录结构与命名符合本仓库约定。

### 问题反馈

> 提交地址：<https://github.com/anyliew/crazy_emoji/issues>

- 单个表情异常请附带**完整报错日志**与**复现截图**
- 请说明运行环境（系统、Python 版本、`meme_generator` 版本）
- 受网络条件限制，答复可能不够及时，请耐心等待
